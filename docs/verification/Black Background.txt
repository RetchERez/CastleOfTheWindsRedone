Castle of the Winds Redone
Black Background v1.0 verification

Both original and patched games ran through Windows 3.1 in DOSBox on an
off-screen Linux display. Each comparison used the same game state in
the original executable and in the standalone Black Background executable.
Part One used a controlled unexplored region in a saved corridor. Part
Two used existing unexplored space in a saved dungeon.

Part One: 18,432 pixels changed. Each changed pixel went from RGB
(255,255,255) to (0,0,0). All differences fell within the map pane.

Part Two: 65,762 pixels changed. Each changed pixel went from RGB
(255,255,255) to (0,0,0). All differences fell within the map pane.

The patch changes the stock brush selected by the unexplored-cell
renderer. Each Black Background executable differs by one byte from its
unmodified v1.1A counterpart. Explored tiles, walls, creatures, controls,
and the status and message areas match the original screenshots.
