# Black Background v1.0

Makes unexplored map cells black in both chapters of the original Win16 *Castle of the Winds* v1.1A. Explored terrain, creatures, and the interface keep their original colors.

Extract the patch ZIP and run this command in its folder. Use `python3` on Linux.

```powershell
py -3 apply_redone.py castl11a.zip Redone-Black-Background
```

You can also pass your extracted original files or an install of DiabloLoot v1.1. Choose a new output folder. Open the matching chapter's EXE in a Win16 runtime, and copy saves separately.
